# 内容映射框架

内容生成器不直接把逐字稿“改写成帖子”。先用三个维度判断素材为什么适合这个创作者。

## 1. 内容板块：长期讲什么

内容板块由用户自己命名，例如创业、AI、健康、消费、职场、亲子、旅行或生活方式。它决定一条内容在账号长期结构中的位置。

通用参考分类见 [选题池](topic-pools.md)，但不得强迫用户采用预设名称。

## 2. 能力信号：希望读者看见自己会什么

常见能力包括：

- 专业知识：能解释复杂概念与行业机制；
- 判断能力：能辨别机会、风险、产品和观点；
- 实践能力：做过、试过，知道执行中的真实问题；
- 解决问题：能提出动作、流程或取舍方案；
- 复盘能力：能从结果中找到原因和可迁移经验；
- 连接能力：能理解人、组织资源、建立合作与社区；
- 发现能力：能发现新品、新场景、新趋势和被忽视的细节；
- 表达能力：能把模糊感受或复杂问题讲清楚。

能力必须有用户确认的经历、案例、结果或现场支撑。没有证据时只能标为“希望建立的能力认知”，不能写成既有成绩。

## 3. 观点资产：希望读者记住自己如何判断

观点资产不是一句漂亮口号，而是长期可重复验证的判断标准，例如：

- 面对机会时，我首先看什么；
- 判断一个产品或服务值不值得，我使用什么标准；
- 对工作、家庭、健康、金钱或成长，我长期相信什么；
- 哪些流行观点我同意、保留或反对；
- 我希望帮助受众增加什么选择、减少什么消耗。

来源观点与用户观点必须分开。逐字稿只能提供触发和证据，不能自动成为用户本人的立场。

## 内容形式

同一板块可以选择不同表达形式：

- 观点判断：给出一个清晰立场和判断标准；
- 经历故事：用真实经历说明一次变化或选择；
- 方法拆解：提供一两个可执行动作，不自动公开完整付费体系；
- 案例复盘：分析一个项目、人物、产品或结果；
- 知识解释：把复杂概念讲清楚；
- 趋势回应：借公共讨论提供自己的判断；
- 资源推荐：说明适合谁、为什么以及使用边界；
- 问题讨论：提出一个值得受众参与的问题，但不使用空洞互动钩子。

## 候选选题映射

每个候选至少回答：

```text
这段素材属于哪个内容板块？
它能展示创作者的什么能力？
它能承载创作者的哪条观点？
有什么本人证据可以接入？
最适合用哪种内容形式和平台？
```

如果无法回答前三项，这段素材不适合进入个性化创作；可以保留为普通笔记，但不强行发布。
